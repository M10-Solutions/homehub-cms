# Mitwirken an HomeHub CMS

Fehler und Verbesserungsvorschläge können nach Veröffentlichung über GitHub Issues gemeldet werden. Bitte keine privaten Inhalte, Zugangsdaten oder Sicherheitslücken öffentlich einstellen; siehe SECURITY.md.

Wir arbeiten spezifikationsorientiert (SDD): Anforderungen und Akzeptanzkriterien in docs/SPEC-EDITOR.md und docs/SPEC-ADMIN.md bzw. TASKS.md abstimmen, kleine Feature-Branches erstellen, Änderungen implementieren, Tests ergänzen, Regression ausführen und Dokumentation aktualisieren. Pull Requests sollen Zweck, Testnachweis und Auswirkungen auf Daten, Berechtigungen und Installation beschreiben. Änderungen an der Benutzeroberfläche zusätzlich manuell prüfen.

Nur eigene oder kompatibel lizenzierte Beiträge einreichen, die unter der Projektlizenz GPL-3.0-or-later weitergegeben werden dürfen. Drittanbieterhinweise erhalten. Keine produktiven Daten oder persönlichen Informationen committen. Ein Pseudonym und eine GitHub-noreply-Adresse sind willkommen.
