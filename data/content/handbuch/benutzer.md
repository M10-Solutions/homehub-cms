# Benutzer und Berechtigungen

Wer darf was sehen und ändern?

| Rolle | Aufgaben |
| --- | --- |
| Reader | Freigegebene Inhalte lesen |
| Editor | Berechtigte Seiten erstellen, bearbeiten und organisieren |
| Admin | Alle Seiten, Benutzer und Berechtigungen verwalten |

Ohne Anmeldung sind nur öffentlich lesbare, veröffentlichte Seiten erreichbar.

## Veröffentlichung und Navigation

- **Veröffentlicht:** Die Seite ist für berechtigte Leser regulär erreichbar.
- **Entwurf:** Nur berechtigte Redakteure und Administratoren können sie redaktionell öffnen.
- **In Navigation anzeigen:** Steuert den Navigationseintrag, nicht die Leseberechtigung.

Administratoren können Seiten für alle, angemeldete Benutzer, bestimmte Rollen oder einzelne Benutzer freigeben. Kapitelberechtigungen gelten für Nicht-Administratoren auch auf Unterseiten. Eine Unterseite kann eine übergeordnete Einschränkung nicht aufheben.

Medien sind davon ausgenommen: Wer die Medien-URL kennt, kann die Datei abrufen. HomeHub 1.0 ist für ein vertrauenswürdiges privates Netzwerk vorgesehen.
