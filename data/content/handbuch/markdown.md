# Markdown-Kurzanleitung

Die wichtigsten Formatierungen auf einen Blick.

Markdown ist einfacher Text mit Formatierungszeichen. Nutze die Vorschau, um das Ergebnis zu kontrollieren.

| Eingabe | Ergebnis |
| --- | --- |
| `**fett**` | **fett** |
| `*kursiv*` | *kursiv* |
| `## Überschrift` | Abschnittsüberschrift |
| `- Eintrag` | Aufzählung |
| `1. Eintrag` | Nummerierte Liste |
| `> Hinweis` | Zitatblock |

## Beispiel

```markdown
## Wartung

- Gerät kontrollieren
- **Backup prüfen**

> Änderungen dokumentieren.
```

Auch Tabellen und Codeblöcke sind möglich. Für interne Links und Bilder verwende am besten die entsprechenden Werkzeuge im Editor.
